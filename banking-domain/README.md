# Welcome to the Banking Domain Documentation!

Understanding the banking world through data and technology. In this workspace, we've organized all the important information about banking into easy-to-read markdown files. Think of this page as a table of contents that helps you jump straight to what you need to learn.

## Why This Matters
Banking is all about managing money, loans, and services safely. By studying these documents, you'll learn how banks store data, handle everyday transactions, and even work on big IT projects. It's like peeking behind the scenes of your bank app!

## Documentation Files
These files explain the big ideas in banking. Each one focuses on a different topic to make learning step-by-step:

- **[Banking Domain Overview](banking_overview.md)**: Get a quick introduction to what banking is all about. Perfect for beginners!
- **[Regular Banking Services Data Model](banking_regular_services.md)**: Learn about everyday banking stuff like checking accounts and transfers. We'll show you how data is structured.
- **[Home Loans Data Model](banking_home_loans.md)**: Dive into home loans – how banks decide who gets a mortgage and how they track payments.
- **[IT Projects in the Banking Domain](banking_it_projects.md)**: Discover the tech side! See examples of projects that improve banking systems.
- **[Integration and Teaching Guidance](banking_teaching_guidance.md)**: Tips on how to connect different banking systems and guidance for teachers on explaining these concepts.

## Python Script Documentation
These are special computer programs (scripts) written in Python that help create sample banking data. They're like tools for practicing. Each script has its own guide:

- **[generate_banking_data.py](generate_banking_data.md)**: A script to make fake banking data for testing and learning.
- **[banking_data_model.py](banking_data_model.md)**: Explains the code that defines how banking data looks in the computer.
- **[generate_postgres_data.py](generate_postgres_data.md)**: Creates data for a database called PostgreSQL, which banks use to store info.
- **[create_dynamodb_tables.py](create_dynamodb_tables.md)**: Sets up tables in DynamoDB, another type of database for fast data access.
- **[generate_dynamodb_data.py](generate_dynamodb_data.md)**: Fills those DynamoDB tables with sample data.

## How to Use This
Click on any link above to open the file and start reading. If you're new, start with the Overview. Ask questions if something's confusing – learning is about exploring!

Remember, this is all about understanding real-world banking through simple examples and clear explanations. Have fun learning!
