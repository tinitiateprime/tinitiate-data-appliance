# Banking Domain Overview

A typical bank's data systems handle millions of customers, accounts, and transactions. The data model must support scalability, security, compliance (e.g., GDPR, CCPA), and real-time processing. We'll use Entity-Relationship Diagrams (ERDs) in Mermaid format to visualize the schemas.

Key principles:
- **Normalization**: Reduce redundancy.
- **Relationships**: One-to-one, one-to-many, many-to-many.
- **Attributes**: Include primary keys, foreign keys, and essential fields.
